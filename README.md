# 基金日记

五只持仓基金的「前一天预测、后一天复盘」日记，PWA，部署在 GitHub Pages，运行不依赖 Claude。

## 这是一个预测实验
验证「我」能不能持续预测 5 只持仓基金的单日涨跌，并证明是否优于简单基准。设计见 [docs/DESIGN.md](docs/DESIGN.md)。

- **我预测**：每个交易日 09:25 前在 app 里给每只基金一个数值和理由，提交即锁定（以 git 提交时间为准，不能覆盖）。
- **系统负责**：时点快照（只含当时已可获得的数据）、信号触发、AI 草稿（对照组）、规则模型、三个基准（跟随外盘 / 昨日延续 / 永远 0%）、评分、复盘、信号状态机、研究集 / 留出集回测门槛。

## 定时任务
- 每晚 22:13：结算当天 → 复盘 → 更新信号状态 → 规则模型升级门槛 → 下一交易日晚间快照与草稿
- 交易日 08:07：早间快照与草稿（隔夜美股已收盘）

## 配置
- Secrets：`GEMINI_API_KEY`
- Pages：main / root
- 手机 app 首次填写前，在「设置」里粘贴一个只对本仓库 Contents 有读写权限的 fine-grained 令牌

## 手动维护
- 加减仓：改 `data/funds.json` 里的 `holding`
- 休市日：每年 12 月补进 `data/calendar.json`
- 参数：`data/config.json`（平盘线、截止时间、研究/留出天数、门槛）

旧版数据在 `data/legacy/`，不参与新统计。预测仅作实验记录，不构成投资建议。
